# Premium Teachers' Day Surprise

A mobile-first Next.js + React + Tailwind + Framer Motion interactive Teachers' Day experience.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Optional music

Place a soft instrumental MP3 at:

`public/music/teachers-day.mp3`

Music is never autoplayed before the first user interaction. The small music control can pause/resume it afterward.

## Visual approach

The page uses CSS/SVG-like vector construction rather than large raster assets, keeping the experience lightweight while still providing layered petals, sparkles, cake, flowers, glass surfaces, glow, cinematic scene transitions and responsive layouts.
